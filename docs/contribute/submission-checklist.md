# Submission Checklist

Before submitting:
- [ ] No personal info (names, emails, phone numbers, IPs, addresses, tokens)
- [ ] No private logs / screenshots that could leak secrets
- [ ] Clear title + audience + prereqs
- [ ] Steps are reproducible
- [ ] Includes verification steps
- [ ] Includes references/sources for non-trivial factual claims
- [ ] Defensive framing for security-related content
- [ ] No illegal instructions / no harassment / no doxxing
